# solarc-eclipse

ECLIPSE is now on PyPI as [eclipse](https://pypi.org/project/eclipse/). Install it with

```bash
pip install eclipse
```

`solarc-eclipse` is its former name. Installing this last release stops with a message saying to install `eclipse`. Versions 0.12.1 and earlier can still be installed by giving the version, such as `pip install solarc-eclipse==0.12.1`.

The documentation is at [solarc-eclipse.readthedocs.io](https://solarc-eclipse.readthedocs.io), and the code at [github.com/jamesmckevitt/eclipse](https://github.com/jamesmckevitt/eclipse).
