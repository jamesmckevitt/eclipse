# solarc-eclipse

ECLIPSE is now on PyPI as [eclipse](https://pypi.org/project/eclipse/). Install it with

```bash
pip install eclipse
```

`solarc-eclipse` is its former name. Installing `solarc-eclipse` installs `eclipse`, so existing installations and instructions still work.

The documentation is at [solarc-eclipse.readthedocs.io](https://solarc-eclipse.readthedocs.io), and the code at [github.com/jamesmckevitt/eclipse](https://github.com/jamesmckevitt/eclipse).
